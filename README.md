# Chika · Shift Control

Приложение для управления сменой одной кофейни: обзор смены, задачи и чек-листы, регистрация инцидентов. Мягкий серый интерфейс адаптирован для компьютера и телефона. Языки — русский и английский, переключатель RU / EN находится сверху.

## Текущая версия

- Обзор смены: открытие/закрытие, показатели, команда, заметка.
- Задачи: чек-листы, добавление, выполнение и фильтры.
- Инциденты: создание, приоритеты, статусы и фильтры.
- Выбор языка и изменения сохраняются в браузере.
- Команда и исходные события вымышлены. Настоящих аккаунтов, API и общей базы данных пока нет.

У каждого браузера отдельные данные. Изменения не передаются другим сотрудникам. Переход с localhost на опубликованный сайт не переносит сохранения автоматически. Не вводите в демонстрацию персональные и рабочие данные.

## Технологии

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4 и Lucide. Команды разработки и сборки используют Webpack. Изображения находятся в public/; внешних шрифтов и аналитики нет.

## Запуск на macOS

Установите Node.js 24 LTS с https://nodejs.org — npm входит в комплект. Глобальные инструменты не нужны.

Скачайте или клонируйте этот репозиторий. В Терминале перейдите в его папку (замените путь на свой):

```bash
cd ~/Projects/chika-shift-control
npm ci
npm run dev
```

После Ready откройте http://localhost:3000. Оставьте терминал открытым. Остановка: Control+C.

## Запуск на Windows

Установите Node.js 24 LTS. В PowerShell или Командной строке перейдите в папку проекта (замените путь на свой):

```powershell
cd C:\Projects\chika-shift-control
npm ci
npm run dev
```

После Ready откройте http://localhost:3000. Если PowerShell блокирует npm.ps1, используйте npm.cmd вместо npm или откройте Командную строку. Менять политику безопасности не требуется.

## Проверка и готовая сборка

Выполняйте команды по очереди:

```bash
npm run typecheck
npm run build
npm start
```

Для проверки на iPhone используйте готовую сборку: iPhone и компьютер должны находиться в одной сети Wi-Fi. В Safari откройте http://IP-КОМПЬЮТЕРА:3000. Компьютер и терминал должны оставаться включёнными. localhost на телефоне обозначает сам телефон.

## Публикация

GitHub хранит исходники и историю изменений. Доступ к опубликованному сайту управляется отдельно на хостинге. Приватный репозиторий может быть источником публичного сайта.

Текущая сборка — Next.js-приложение. Для автоматической публикации подключите репозиторий к хостингу с поддержкой Next.js, например Netlify или Vercel, и следуйте его настройкам. Сам перенос на GitHub не подключает автоматическую публикацию и не меняет существующий сайт. Для ручного статического экспорта нужен отдельный next.config.mjs с output: 'export' и trailingSlash: true; после npm run build на статический хостинг загружается папка out/.

## Структура

- app/page.tsx — обзор смены.
- app/tasks/page.tsx — задачи.
- app/incidents/page.tsx — инциденты.
- app/globals.css — оформление.
- components/store.tsx — состояние и localStorage.
- components/language.tsx и lib/translations.ts — языки интерфейса.
- lib/data.ts — типы, демоданные и обновление старых имён.
- public/ — логотип и иллюстрация кофейни.

Задачи, инциденты, заметка и состояние смены: shift-control:v1. Язык: shift-control:language. Ранее выбранный логотип: shift-control:logo:v1. Очистка данных сайта удаляет эти сохранения.
